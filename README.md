# UED WorkBuddy

UED 部门的 AI 设计工作台，可点击的高保真演示版本。

**在线打开**：https://mic-ued-cloud-design.github.io/ued-workbuddy/

## 这是什么

把部门已有的设计能力收进一个入口：新建任务、我的项目、资料库、技能与规范。
六个常见场景各自带好模板，不需要自己想怎么描述需求。

演示版本使用预置内容，没有接入真实模型和真实技能，用来看形态和流程，不能实际执行任务。

## 文件

单个 HTML 文件，不依赖任何外部资源，也不需要构建。下载 `index.html` 双击即可打开，断网也能用。

## 怎么更新

改 `index.html` → 提交 → 推送。GitHub Pages 约一分钟后自动更新线上页面。

```bash
git commit -am "说明这次改了什么"
git push
```
