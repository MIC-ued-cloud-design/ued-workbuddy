# 飞鹊设计规范 · 使用规则

> `tokens.json` 给的是**值**（color 78 个、fontSize 26 个、shadow 11 个、corner 8 个…），
> 这份给的是**什么时候用哪个**。内容逐条取自飞鹊组件库的规范页
> （颜色 / Typography 字体 / Space 间距 / Corner 圆角 / Shadow 阴影 / 无障碍设计），2026-09-15 读出。

## 1. 间距 · 7 级 token 各自的场景

基于 **4px 网格**，变量集合 `spacing`。

| token | 倍数 | 用在哪 |
|---|---|---|
| 4px | ×1 | icon 内间距 · 紧凑元素间隙 · 标签内 padding · ★图标与文字间距 · checkbox 与 label |
| 8px | ×2 | 组件内 padding · 相关元素间距 · 列表项 padding(small) · ★表单项间距 · 列表分割线到内容 |
| 12px | ×3 | 卡片内 padding · 表单字段间距 · 列表项 padding(default) · ★段落间距 · 表单 label 到输入框 |
| 16px | ×4 | 区块内 padding · 段落间距 · 模块内部间距 · ★卡片内 padding · 模块标题到内容 |
| 24px | ×6 | 区块间距 · 卡片间距 · 主要模块分隔 · ★模块间距 · 区块标题到卡片 |
| 32px | ×8 | 区块内分组间距 · 响应式断点常用 · 大区块间距 · 页面区域分隔 · ★section 间距 · footer 上方间距 |
| 48px | ×12 | 页面级间距 · 首屏到内容区 · 大段落分隔 · ★大区块分隔 |

🔴 **规则**：所有间距从这 7 个 token 里选。7 个不够时允许其他 4px 倍数（20/28/36/40），
**禁止非 4px 倍数（5/10/15/25）**。
🔴 **间距是层级信号**：同级元素用相同间距，不同层级用不同间距拉开视觉距离。

## 2. 圆角 · 外大内小与等大公式

| 值 | 用在哪 |
|---|---|
| 4px | 标签、小型按钮 |
| 6px | 默认按钮、输入框、卡片 |
| 12px | 大型卡片、模态框 |
| 9999px | 全圆（胶囊/圆形） |

🔴 **视觉等大原则**：外圆角（容器边框）和内圆角（内容区域）要看起来一样大，
但因为透视和背景差异，得用公式调：

```
外圆角 = 内圆角 + padding
例：内圆角 16px + 内边距 8px = 外圆角 24px
```

组合圆角（卡片里既有外容器又有按钮）遵循**「外大内小」或「同级统一」**。
紧凑主题下所有圆角可按比例（约 0.8 倍）减小。

## 3. 阴影 · 三级是层级语义，不是深浅档位

| 层级 | 什么东西 | 视觉 | 参数（三层叠加） |
|---|---|---|---|
| 低 | 下拉面板等：被操作时浮起，操作完就落回原层级 | 贴近背景，柔和微弱 | x0 y1 B0 S1 10%#000 · x0 y3 B6 S-4 12%#000 · x0 y6 B16 S-8 8%#000 |
| 中 | 卡片 hover：由地面元素展开，跟随所在层级移动 | 浮起一定高度，阴影清晰 | x0 y6 B6 S1 · x0 y9 B16 S0 · x0 y12 B28 S0，5%#000 |
| 高 | 对话框、模态框、通知、抽屉：运动与其他层级无关联 | 显著突出于界面之上，强烈且扩散 | x0 y5 B12 S4 · x0 y9 B28 S8 · x0 y12 B48 S16，3%#000 |

🔴 **建议两层阴影组合**：一层负责大范围柔和扩散，一层负责底部清晰边界，模拟自然光线。
（DESIGN.md 里的 `.shadow-1/-2/-3` 就是这三级；**全用或全不用**，别混。）

## 4. 字体

- 字体栈：`"Roboto", "Arial", "Microsoft YaHei", "sans-serif"`（英文和数字都用 Roboto）
- **字重只有两种**：400 常规 / 700 加粗
- **主力字号 14px / 行高 22px**；Button 高 32px、input 高 32px
- 字阶层级：特大标题（运营专题/功能介绍）· 大标题（页面/模块标题）· 中标题（页面/模块标题）· 小标题（正文标题）
- 🔴 **字阶控制在 3–5 种之间，保持克制**；其余字阶按 1.5 / 1.2 倍自由定义

## 5. 颜色语义

主色系用途：**主按钮色、边框、icon、logo**；另有 hover 档。
中性色 neutral color-1 ~ -5 分别对应：强调/正文标题 · 描边 icon · 框背景 / 线按钮 hover / dark background 等。
具体色值以 `tokens.json` 与 `DESIGN.md` 第 2 节为准，这里只说用途。

## 6. 无障碍（WCAG 2.1 AA）

飞鹊规范页的原文要求，**包里此前完全没有这部分**。

### 四大原则

**① 可感知** — 非文本内容（图片/图标/视频）必须有替代文本 Alt，纯装饰性 Alt 设为空（`alt=""`）；
视频/音频提供字幕或文字稿；**内容与背景对比度 ≥ 4.5:1**（大文本 ≥ 3:1，大文本指 ≥18pt/24px 普通字、
≥14pt/18.66px 粗体）；支持文字缩放至少 200% 不错乱，**禁止用 px 固定容器宽度导致文字溢出**；
**纯色彩不能作为唯一信息载体**（"红色代表错误"要搭配图标或文字）；结构语义化（h1-h6 / nav / main / aside）。

**② 可操作** — 所有交互元素支持键盘 Tab 导航、Enter 确认、ESC 关闭，**无键盘陷阱**；
**焦点样式不能被隐藏**（禁止 `outline:none` 且无替代），需高对比度焦点框；
**按钮/链接最小点击尺寸 ≥ 44×44px**；表单提交、倒计时支持暂停或延长；
弹窗打开时焦点自动移入、关闭后返回原位置；闪烁频率 ≤ 3 次/秒。

**③ 可理解** — 语言简洁，避免过度专业术语；全站导航结构与交互方式统一；
表单 **label 绑定 id**、必填项明确、错误提示具体（"手机号需 11 位数字"而不是"输入错误"）；
**避免模糊链接文字**（"点击这里"→"点击查看订单详情"）；一个页面仅一个 h1。

**④ 鲁棒性** — 优先用原生语义标签（button/a/input/nav/main），而不是 div 模拟；
**ARIA 仅在原生语义不够时使用**，禁止滥用（别给原生 button 加 `role="button"`）；
兼容 NVDA / VoiceOver / JAWS；动态内容通过 ARIA Live Region 通知屏幕阅读器。

### MIC 的焦点样式

```
2px #0071E1（主题蓝-hover）50% 透明，圆角 4px，偏移 1~2px
```

### 交付前自查 10 条

1. 全页面可纯键盘操作（Tab/Enter/ESC/方向键）
2. 所有焦点元素有清晰焦点样式，无焦点陷阱
3. 内容与背景对比度 ≥ 4.5:1（用 WebAIM Contrast Checker 验）
4. 所有图片有 Alt，纯装饰图 Alt 为空
5. 表单有 label 绑定，错误提示具体，必填项明确
6. 弹窗支持 ESC 关闭和蒙层点击关闭，焦点可返回
7. 文字缩放 200% 后布局无错乱、内容无溢出
8. 纯色彩不单独作为信息载体，搭配图标或文字
9. 链接文字无模糊表述
10. 使用语义化 HTML 标签，h1-h6 层级有序
